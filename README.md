# ماه‌نگار | MahNegar

اپلیکیشن تقویم فارسی مینیمال برای Android با Flutter.

## قابلیت‌های هدف
- تقویم شمسی، میلادی و قمری
- مناسبت‌ها و تعطیلات رسمی ایران
- رویداد، کارهای روزانه و یادآوری
- بخش آسمان، فاز ماه و اطلاعات نجومی
- قمر در عقرب با تفکیک برج عقرب و صورت فلکی عقرب
- بخش Astrology مجزا از اطلاعات نجومی واقعی
- رابط فارسی RTL با فونت IranSans
- Light / Dark Mode
- ذخیره آفلاین و Backup / Restore
- اعلان‌های محلی
- GitHub Actions برای ساخت APK و AAB

## ساختار پیشنهادی
- `lib/core` زیرساخت و سرویس‌ها
- `lib/features/calendar` تقویم
- `lib/features/events` رویدادها
- `lib/features/todos` کارها
- `lib/features/astronomy` نجوم
- `lib/features/astrology` استرولوژی
- `lib/features/settings` تنظیمات
